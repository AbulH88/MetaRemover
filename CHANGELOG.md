# Changelog

## 1.3.0

First public release of MetaRemover for Windows x64.

- Bulk image/video import, selected/all export, progress, cancellation, and original-file preservation.
- Metadata removal and editable iPhone 11–16/SE profiles with automatic daylight examples.
- Saved custom presets with persistent save/update/delete.
- Missing-capture-date fallback using a batch export timestamp.
- JPG/JPEG, PNG, WebP, MP4 and MOV support with metadata verification.
- iPhone-style naming, rollover, collision handling, optional folder preservation.
- Resizable settings and metadata preview.
- Self-contained installer and portable ZIP with SHA-256 checksums.

Validation: 61 automated tests plus native UI and installed-app checks. HEIC/HEIF and RAW are not supported.
